# Grade Management System

A console-based C++ application for managing student records.

## Features

* Add Student
* View All Students
* Search Student
* Delete Student
* Calculate Class Average
* Show Highest Score
* Show Lowest Score
* Automatic Grade Calculation

## Concepts Used

* Arrays
* Functions
* Loops
* Conditional Statements
* Linear Search
* Input Validation
* Array Element Shifting

## Technologies

* C++
* Standard Library (iostream, string)

## Learning Goals

This project was built to practice C++ fundamentals including arrays, functions, searching algorithms, and menu-driven program design.
